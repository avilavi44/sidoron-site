לדבר עם הסידור: חיבור סידורון ל-Claude ול-ChatGPT

אפשר לחבר את סידורון לעוזר AI ולשאול אותו בעברית רגילה: ״מי לא ענתה עדיין לשבוע הבא?״, ״מה חסר ביום שלישי?״, ״דנה חולה מחר, תמצא לה מחליפה״. העוזר רואה ועושה רק מה שמותר לך באפליקציה.

כתובת החיבור

https://ipdqnfqhxtbkmhbtjodm.supabase.co/functions/v1/mcp

בזמן החיבור ייפתח דף כניסה של סידורון. נכנסים עם אותו חשבון Google של האפליקציה ומאשרים.

Claude (באתר, באפליקציה ובמחשב)

  1. הגדרות ← Connectors ← Add custom connector.
  2. שם: סידורון. כתובת: הכתובת שלמעלה. ← Add.
  3. לוחצים Connect, נכנסים לסידורון ומאשרים.
  4. בשיחה חדשה מדליקים את סידורון בתפריט הכלים ושואלים.

ChatGPT

  1. Settings ← Apps & Connectors ← Advanced ← מדליקים Developer mode.
  2. חוזרים ל-Apps & Connectors ← Create. שם: סידורון. כתובת: הכתובת שלמעלה. Authentication: OAuth.
  3. נכנסים לסידורון ומאשרים. בשיחה בוחרים את סידורון מתפריט ה-+.

Claude Code ועוזרים אחרים

claude mcp add --transport http sidoron https://ipdqnfqhxtbkmhbtjodm.supabase.co/functions/v1/mcp

כל עוזר שתומך ב-MCP עם OAuth עובד עם אותה כתובת.

מה העוזר יכול לעשות

  • להציג את הטבלה הגדולה של שבוע: מי יכולה מתי, מי לא ענתה, מה חסר.
  • להציג צוות, סידור, לוח שנה והיעדרויות.
  • לעדכן זמינות, לדווח ״לא אוכל להגיע״, להציע מחליפות.
  • לרכזות: שיבוץ אוטומטי, שיבוץ ידני, קריאה פתוחה, תזכורת למי שלא ענתה, פרסום השבוע.

לפני פעולה ששולחת הודעות לצוות העוזר מבקש אישור. הניתוק נעשה מתוך העוזר בכל רגע. מדיניות הפרטיות
